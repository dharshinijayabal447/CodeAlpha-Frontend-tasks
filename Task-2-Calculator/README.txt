CODEALPHA FRONTEND TASK 2 — ANIMATED CALCULATOR

FILES
- index.html: calculator and history layout
- style.css: responsive styling, animation and dark theme
- script.js: calculator operations, keyboard support, history and interaction animations

HOW TO RUN
1. Keep all four files in the same folder.
2. Open index.html in a browser, or use Live Server in VS Code.

FEATURES
- Addition, subtraction, multiplication and division
- Decimal, percentage, sign toggle, delete and all-clear
- Keyboard support
- Dark mode
- Calculation history with up to 20 recent calculations
- Click a history entry to reuse its result
- History saved in browser localStorage
- Animated page entrance, display feedback, button hover/press, ripple effect and history entries
- Responsive layout and reduced-motion accessibility support\n
